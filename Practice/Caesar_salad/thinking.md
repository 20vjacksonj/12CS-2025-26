# Problem
- design and code an OO based solution to encrypt and decrypt a message using the Caesar Cipher
# Key terms
    - Plain text message (PTM) - the message is in plain text
    - Cipher text message (CTM) - the message after encryption 
    - Shift key (SK) - numerical value the PTM has been shifted by 
# Broad principles
- User needs to provide SK
- The user needs to provide PTM
- The system must treat alpahbet as circular

# Techy stuff
- ord() returns ASCII number from letter
- chr() returns ASCII letter from number
